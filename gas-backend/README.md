# QT 인증 집계 — Google Apps Script 백엔드 배포 가이드

`Code.gs`는 버전관리용 사본입니다. 실제 실행은 Apps Script 에디터에서 이루어지므로, 아래 순서대로 직접 배포해야 합니다.

1. 새 Google Sheet를 만듭니다 (예: "QT 인증 백엔드 DB").
2. 그 시트에서 **확장 프로그램 → Apps Script**를 엽니다. (컨테이너 바인딩 스크립트가 생성되어 별도 스프레드시트 ID 설정 없이 `SpreadsheetApp.getActive()`가 이 시트를 가리킵니다.)
3. 기본으로 생성된 `myFunction` 등 보일러플레이트를 지우고, 이 저장소의 `Code.gs` 전체 내용을 붙여넣습니다.
4. 에디터 상단 함수 선택 드롭다운에서 `setupSheets`를 선택하고 **실행**합니다. 처음 실행 시 "Google에서 확인하지 않은 앱" 경고가 뜨면 **고급 → (프로젝트 이름)로 이동 → 허용**을 클릭하세요. (본인 스크립트가 본인 시트에 접근하는 것이므로 안전합니다.) 이 단계로 `Roster`/`Mapping`/`Excluded`/`PhotoExcluded`/`Settings`/`Records`/`ManualOverrides`/`Readings` 탭과 헤더가 자동 생성됩니다. 기존 백엔드를 업데이트할 때도 새 `ManualOverrides` 탭 생성을 위해 `setupSheets`를 다시 실행하세요.
5. 왼쪽 톱니바퀴(**프로젝트 설정**) → **스크립트 속성** → **속성 추가**: 키 `ACCESS_CODE`, 값에 원하는 접근 코드(비밀번호)를 입력합니다. 이 값은 `Code.gs`(git에 커밋되는 파일)에는 절대 적지 않습니다.
6. **배포 → 새 배포**: 유형은 **웹앱**. "실행 계정"은 **나**, "액세스 권한"은 **모든 사용자**로 설정합니다. (URL만 안다고 데이터가 노출되는 게 아니라, `Code.gs` 내부의 `ACCESS_CODE` 검증이 실제 접근 제어를 담당합니다.)
7. 요청되는 권한(스프레드시트, 외부 URL 호출)을 승인합니다.
8. 배포 후 나오는 웹앱 URL을 복사합니다. `/exec`로 끝나는 URL을 사용하세요 (`/dev`는 에디터 로그인 상태에서만 동작하는 테스트용 URL입니다).
9. 앱의 **명단·설정** 탭 → "백엔드 동기화" 카드에 이 URL과 5번에서 정한 접근 코드를 입력합니다.
10. "가져오기"/"보내기" 버튼으로 테스트한 뒤, 구글 시트를 직접 열어 각 탭에 데이터가 실제로 채워졌는지 확인하세요.

## 이후 코드를 수정할 때

`Code.gs` 내용을 바꾼 뒤에는 **배포 → 배포 관리 → (연필 아이콘) → 새 버전**으로 다시 배포해야 실제 `/exec` 엔드포인트에 반영됩니다. 그냥 저장만 하면 반영되지 않습니다.

## 자동 동기화 동작 방식

프런트엔드는 URL과 접근 코드가 입력되어 있으면 자동으로 동기화합니다. 버튼("지금 가져오기"/"지금 보내기")은 즉시 강제 동기화용이고, 평소에는 아래처럼 자동으로 돌아갑니다.

- **자동 보내기**: 명단·매핑·제외명단·설정·기록·본문 중 하나라도 바뀌면 2초 후 자동으로 서버에 전송(짧은 시간에 여러 번 바뀌면 마지막 한 번만 전송되도록 디바운스).
- **자동 가져오기**: 앱 화면이 보이는 동안 15초마다 자동으로 서버 최신 데이터를 가져와 반영. 다른 탭에 가 있거나 입력창에 커서가 있는 동안은 건드리지 않고 다음 주기에 다시 시도.
- GAS는 웹소켓 같은 진짜 실시간 푸시를 지원하지 않으므로, 이 15초 주기 폴링이 "실시간 공유"를 흉내 내는 방식입니다. 완전한 실시간은 아니며, 최대 15초 정도 지연이 있을 수 있습니다.
- **주의**: 두 사람이 비슷한 시각에 같은 날짜의 기록을 동시에 고치면, 나중에 반영되는 쪽이 앞의 수정을 덮어씁니다(전체 교체 방식, 병합 아님). 실수로 덮어썼다면 각 기기의 "백업 파일 저장"으로 미리 받아둔 JSON이나 구글 시트의 파일 → 버전 기록으로 복구하세요.

## (선택) 매일 아침 본문 캐시 예열

Apps Script 에디터 왼쪽 **트리거(시계 아이콘)** → **트리거 추가** → 함수 `cacheTodayReading`, 이벤트 소스 "시간 기반", "일 타이머"를 원하는 시간대(예: 오전 6시)로 설정하면, 사용자가 앱을 열기 전에 미리 오늘의 본문을 캐싱해 첫 요청 지연을 줄일 수 있습니다. 없어도 동작에는 문제 없습니다.

## 접근 코드에 대한 주의

접근 코드는 실제 로그인 인증이 아니라 단순 공유 비밀번호입니다. 코드를 아는 사람은 누구나 전체 데이터를 읽고 쓸 수 있습니다. 기기를 분실했거나 유출이 의심되면 스크립트 속성의 `ACCESS_CODE` 값을 바꾸고 앱 사용자들에게 새 코드를 다시 공유하세요.
