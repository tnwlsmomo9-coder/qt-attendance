QT인증 집계

카톡 큐티방 대화를 붙여넣으면 누가 언제 QT 인증을 했는지 자동으로 집계하고, 월간 나눔표를 만들어주는 도구입니다.

  • 대화를 붙여넣거나 파일(.txt/.csv)로 올리면 전체 기간을 한 번에 집계
  • 대화방 표시 이름을 명단의 실명과 연결(매핑)
  • 출석률·연속일수 계산, 월간 나눔표를 PDF·PNG·CSV로 내보내기

대화 원문은 서버로 전송되지 않고 이 브라우저에만 저장됩니다.

대화 붙여넣기

카톡 대화방에서 '대화 내보내기'한 텍스트를 통째로 붙여넣으세요. 대화에 포함된 모든 날짜를 한 번에 집계합니다. 카톡 원문은 서버로 전송되지 않고 이 브라우저에만 저장됩니다.

집계 결과

이름오늘출석률(월)연속(월)

발신자 매핑

최근 분석에서 발견된 표시 이름을 명단의 실명에 연결하세요. 표시 이름에 명단 이름이 포함돼 있으면(이모지·직함이 붙어 있어도) 별도 연결 없이도 자동으로 매칭됩니다. 한 번 연결하면 다음부터 자동으로 매칭됩니다.

명단

여부 표에 표시될 실명 목록입니다. 이름을 클릭해 바로 수정할 수 있습니다 — 수정하면 매핑·기록도 함께 옮겨집니다. 「집계」 탭에서 분석을 실행하면 각 사람에게 연결된 카톡 표시 이름을 여기서 바로 확인·수정할 수 있어요.

제외 이름

운영자·봇 등 집계에서 제외할 대화방 표시 이름입니다.

사진 인증 제외

사진만 보낸 메시지는 기본적으로 인증 완료로 인정합니다. 다만 QT 사진이 아니라 기록표 등 다른 사진을 올리는 사람이 있다면, 그 사람의 대화방 표시 이름을 추가해 사진 자동 인정에서 제외하세요. (글자로 쓴 인증은 그대로 인정됩니다)

감지 설정

"[공지]", "공지:", "안내드립니다" 처럼 공지로 보이는 문구가 담긴 메시지나, 묵상사이트 링크만 붙여넣고 별다른 글이 없는 메시지는 길이와 상관없이 자동으로 인증에서 제외됩니다.

PDF/PNG 표시 정보

매일성경(sum.su.or.kr) 오늘의 묵상에서 본문을 자동으로 가져옵니다.

앱을 열지 않아 자동으로 못 가져온 과거 날짜의 본문을 직접 채워 넣을 수 있습니다.

표의 날짜 칸을 클릭하면 빈칸 → O → - 순으로 바뀝니다. 자동 판정이 틀렸을 때 직접 고칠 수 있어요.

「명단·설정」 탭에서 명단을 먼저 등록하세요.
