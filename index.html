카톡 큐티방 대화를 붙여넣으면 누가 언제 QT 인증을 했는지 자동으로 집계하고, 월간 나눔표를 만들어주는 도구입니다.

신천중부교회 QT인증 집계

대화 붙여넣기

카톡 대화방에서 '대화 내보내기'한 텍스트를 붙여넣으세요. 처음엔 지금까지의 대화를 통째로 붙여넣고, 그다음부터는 새로 생긴 날짜분만 붙여넣어도 됩니다 — 이전에 분석한 내용은 계속 기억하고 있다가 새로 넣은 내용을 이어 붙여서 누적 집계합니다. 카톡 원문은 서버로 전송되지 않고 이 브라우저에만 저장됩니다.

발신자 매핑

최근 분석에서 발견된 표시 이름을 명단의 실명에 연결하세요. 표시 이름에 명단 이름이 포함돼 있으면(이모지·직함이 붙어 있어도) 별도 연결 없이도 자동으로 매칭됩니다. 한 번 연결하면 다음부터 자동으로 매칭됩니다.

명단

여부 표에 표시될 실명 목록입니다. 이름을 클릭해 바로 수정할 수 있습니다 — 수정하면 매핑·기록도 함께 옮겨집니다. 「집계」 탭에서 분석을 실행하면 각 사람에게 연결된 카톡 표시 이름을 여기서 바로 확인·수정할 수 있어요.

제외 이름

운영자·봇 등 집계에서 제외할 대화방 표시 이름입니다.

사진 인증 제외

사진만 보낸 메시지는 기본적으로 인증 완료로 인정합니다. 다만 QT 사진이 아니라 기록표 등 다른 사진을 올리는 사람이 있다면, 그 사람의 대화방 표시 이름을 추가해 사진 자동 인정에서 제외하세요. (글자로 쓴 인증은 그대로 인정됩니다)

감지 설정

"[공지]", "공지:", "안내드립니다" 처럼 공지로 보이는 문구가 담긴 메시지나, 묵상사이트 링크만 붙여넣고 별다른 글이 없는 메시지는 길이와 상관없이 자동으로 인증에서 제외됩니다.

PDF/PNG 표시 정보

매일성경(sum.su.or.kr) 오늘의 묵상에서 본문을 자동으로 가져옵니다.

앱을 열지 않아 자동으로 못 가져온 과거 날짜의 본문을 직접 채워 넣을 수 있습니다.

데이터 백업·복원

현재 기기에 저장된 명단·매핑·설정·QT 완료기록·날짜별 본문을 JSON 파일로 백업하거나 다시 복원할 수 있습니다. 카카오톡 대화 원문은 개인정보 보호를 위해 백업 파일에 포함하지 않습니다.

이 백업 형식은 나중에 백엔드 동기화를 붙일 때 그대로 전송할 수 있도록 버전 정보를 함께 저장합니다.

백엔드 동기화

Google Apps Script 백엔드를 연결하면 여러 기기·관리자가 명단·매핑·설정·QT 기록·날짜별 본문을 자동으로 공유합니다 — 이 기기에서 뭔가 바뀌면 잠시 후 자동으로 서버에 보내고, 화면을 보고 있는 동안 15초마다 서버 최신 내용을 자동으로 가져옵니다. 아래 버튼은 지금 바로 강제로 동기화하고 싶을 때만 누르면 됩니다. 카카오톡 대화 원문은 여기서도 전송되지 않습니다. 배포 방법은 gas-backend/README.md를 참고하세요.

주의: 두 사람이 비슷한 시간에 같은 날짜 기록을 고치면 나중에 반영된 쪽이 앞의 수정을 덮어씁니다. 문제가 생기면 「데이터 백업·복원」의 백업 파일로 되돌릴 수 있습니다.

표의 날짜 칸을 클릭하면 빈칸 → O → - 순으로 바뀝니다. 자동 판정이 틀렸을 때 직접 고칠 수 있어요.

「명단·설정」 탭에서 명단을 먼저 등록하세요.
